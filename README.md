A tool that loads .mjml snippets and creates one .mjml and .html based on user input. Made with sveltekit

More functionalty:

- [ ] Newsletter content is saved in a seperate projects folder that is tracked via git
  - [ ] projects folder continains one or more folders for each project
  - [ ] project folder contains a template.mjml, item.mjml and a folder that contains all the ‘instances’ (we need a better name) of the newsletters.
  - [ ] Text content of those instances are saved in a .md file and is loaded dynamically
- [ ] User can view and edit template.mjml and item.mjml
- [ ] User van preview the resulting .mjml and .html
- [ ] User can change/update UTM tags
- [ ] User can test for broken links
